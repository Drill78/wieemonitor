# 分阶段开发路线图（ROADMAP.md）

> 本文件按"可独立验证的小阶段"组织开发任务。
> 每个阶段都有明确的**目标**、**交付物**和**验证方式**。
> 完成一个阶段后必须停下来确认，再决定是否进入下一阶段。

---

## 阶段 0：UI 骨架（**当前阶段**）

**目标**：搭起一个能在浏览器里看见地图的最小 Next.js 应用，用假数据演示交互流程。

**交付物**：

- Next.js 14+ 项目初始化（TypeScript + Tailwind + App Router）
- 安装 react-leaflet + leaflet + 必要类型
- 首页 `/`：
  - 全屏地图，初始视图聚焦**山西省**
  - 用 OpenStreetMap 作为底图
  - 在地图上画 **3 个示意保护区多边形**（假数据，coordinates 可粗略给出）
- 点击保护区 → 弹出（或滑出）侧边栏，显示该保护区的占位信息（保护区名 + "样线列表加载中..."占位文字）
- 不涉及任何数据库，所有数据写在 `src/data/mock/` 下

**验证方式**：

- 浏览器打开 `http://localhost:3000`
- 看到山西省地图 + 3 个保护区多边形
- 点击多边形 → 弹出侧边栏 + 保护区名

---

## 阶段 1：样线数据

**目标**：在保护区侧边栏里展示该保护区的样线列表，点击样线在地图上高亮。

**交付物**：

- 假数据：每个保护区 3-5 条样线（LineString）
- 侧边栏内列出样线（编号 + 长度 + 调查日期）
- 点击某条样线 → 地图上该样线高亮显示（颜色变化 / 加粗）
- TypeScript 类型 `Transect` 定义在 `src/types/transect.ts`

**验证方式**：

- 点击保护区 → 侧边栏出现样线列表
- 点击样线 → 地图上对应线条高亮

---

## 阶段 2：红外相机数据

**目标**：在样线沿途展示红外相机点位，点击相机查看照片。

**交付物**：

- 假数据：每条样线沿途 3-8 个相机部署点
- 选中样线后，地图上叠加该样线的相机 marker
- 点击相机 marker → 弹出图片查看器（modal 或 popover）
- 图片用 `public/sample-images/` 下的几张示例图片（先共用同一组）
- TypeScript 类型 `Camera`、`Photo` 定义在 `src/types/`

**验证方式**：

- 选中样线 → 地图上看到相机 marker
- 点击相机 → 看到照片列表 / 大图

---

## 阶段 3：引入数据库

**目标**：把假数据替换为真实数据库，搭起完整的数据闭环。

**交付物**：

- `docker-compose.yml`：PostgreSQL 16 + PostGIS
- 选定 ORM（Prisma 或 drizzle）并配置
- 设计 schema（详见 `DATA_MODEL.md`）：
  - 保护区 `reserves`
  - 样线 `transects`
  - 相机 `cameras`
  - 照片 `photos`
- 数据导入脚本 `scripts/import/`：
  - 从 Excel 导入保护区、相机元数据
  - 从 shapefile / GPX 导入样线几何
  - 从图片目录批量录入照片记录
- API Routes：
  - `GET /api/reserves`
  - `GET /api/reserves/:id/transects`
  - `GET /api/transects/:id/cameras`
  - `GET /api/cameras/:id/photos`
- 前端从 mock 切换到 fetch 真实 API

**验证方式**：

- 数据库里至少有 1 个保护区、5 条样线、20 个相机、100 张照片
- 前端展示与阶段 2 一致，但数据来自数据库
- 关闭 Docker 数据库 → 前端报错（说明确实在用数据库）

## 阶段 4：生物信息 + 声音数据

**目标**：把另外两类数据接入。具体细节根据实际数据格式定，先把骨架搭起来。

**交付物**：

- 数据库 schema：`biology.samples`、`acoustic.recordings`（字段待与项目所有者细化）
- 侧边栏增加"生物样本"、"声音记录"两个 tab
- 基础展示 UI：
  - 生物：列表 + 详情（物种、采样位置、测序结果链接）
  - 声音：列表 + 内嵌音频播放器
- 音频文件存 `public/sample-audio/`（开发阶段）

**验证方式**：

- 选中保护区 / 样线 → 能切到生物 / 声音 tab
- 能播放示例音频
- 能看到生物样本列表（即便字段还粗糙）

---

## 阶段 5：部署

**目标**：把整套系统跑到单位的服务器电脑上，让同事能访问。

**交付物**：

- `Dockerfile` + `docker-compose.prod.yml`
  - Next.js 应用容器
  - PostgreSQL + PostGIS 容器
  - Volume 映射：照片 / 音频目录、数据库数据
- 部署文档 `docs/DEPLOY.md`：
  - 服务器初始化步骤（Docker 安装、目录权限）
  - 启动 / 停止 / 备份命令
  - 内网访问配置
  - Cloudflare Tunnel 配置（可选）
- 基础用户权限：
  - 简单登录（用户名 + 密码，先不做注册）
  - 区分管理员 / 查看者

**验证方式**：

- 同事在自己电脑用浏览器打开 `http://<服务器内网IP>:3000` 能正常使用
- 服务器重启后服务自动恢复
- （可选）外部用户通过 Cloudflare Tunnel 域名能访问
